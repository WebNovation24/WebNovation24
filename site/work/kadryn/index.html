01 · Problem

A retry must not become new usage.

One concrete failure mode made the product contract testable: the same usage submission can arrive twice while monthly quota state is contested.

Constraint

Preserve the safeguards

Tenant, retention and quota rules could not be weakened just to make retries idempotent.

Scope decision

Fix ordering, not the whole pipeline

I kept the change narrow: resolve known exact replays before avoidable quota contention, then re-check inside the critical section for concurrent first submissions.

User/product consequence

Retries stop looking like new intent

The system can distinguish a repeated request from genuinely new usage without hiding concurrency behind optimistic UI semantics.

02 · What I built

Product semantics backed by a real TypeScript system.

I owned the path from product meaning to backend behavior and verification rather than treating UI copy, ingestion and release evidence as disconnected work.

03 · Decisions & trade-offs

Three decisions kept the system honest without overbuilding it.

The goal was not maximum architecture. It was the smallest reliable slice that preserved the product invariants worth protecting.

Replay ordering

Recognize a known replay before unnecessary quota contention.

Then re-check replay state inside the lock so two concurrent first submissions cannot both become new usage.

Product authority

Recommendation is not execution.

A recommendation can inform a decision; it cannot silently become runtime control or be reported as measured business impact.

Scope control

Strengthen the invariant before broadening the surface.

I preferred a narrow verified behavior with regression coverage over a larger rewrite that would increase change surface without improving the core guarantee.

04 · Evidence

A hiring manager can inspect the concurrency invariant.

The private product stays private. A small independently written public reproduction makes the ordering and regression behavior reviewable without presenting it as production source.

Implementation invariant
const knownReplay =
  await repo.findExactReplay(command);

if (knownReplay) return asReplay(knownReplay);

return repo.withMonthlyQuotaLock(
  tenantId,
  month,
  async () => {
    const concurrentReplay =
      await repo.findExactReplay(command);

    if (concurrentReplay) return asReplay(concurrentReplay);

    return applyQuotaAndInsert(command);
  },
);
